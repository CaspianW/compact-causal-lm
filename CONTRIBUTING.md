# Contributing

## Commit messages

Use this format for commit messages:

```text
[Type]: concise English description
```

Keep the description short and specific. Common types include:

- `New`: add a new feature or file
- `Modify`: change existing behavior or implementation
- `Fix`: fix a bug or incorrect behavior
- `Refactor`: restructure code without changing behavior
- `Docs`: update documentation
- `Test`: add or update tests
- `Chore`: maintenance work

Examples:

```text
[New]: Add validation dataset loader
[Modify]: Update model forward pass
[Fix]: Handle empty input batches
```
